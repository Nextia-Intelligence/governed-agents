# Exercise 7: phone numbers stay out of the log

**Time:** about 20 minutes.

Customers sometimes put a phone number in a ticket, and Sam's reply may quote it.
Today the audit log removes emails, names and addresses, but it keeps phone numbers.

## Your task

In `src/bluekite/governance/audit.py`, change `redact_text()` so that phone numbers become
`[phone]`. Handle at least these forms:

- `+1 416 555 0199`
- `416-555-0199`
- `(416) 555-0199`

Ids and money must stay as they are: `O-5002`, `C-102`, `r-0001` and `$2,000.00` are not
phone numbers.

## Done when

```
uv run pytest exercises/check_s07.py -q
uv run pytest -q
```

Both pass. Then run `bluekite reset && bluekite run --all && bluekite audit verify`: the
chain is still intact.
