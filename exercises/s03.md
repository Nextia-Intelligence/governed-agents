# Exercise 3: no refunds on a closed account

**Time:** about 25 minutes.

When a customer's account is closed, a person handles any money that is still owed. Sam must
not refund an order whose customer account is closed.

## Your task

Add a rule with the id `no-refund-on-closed-account` (effect: deny), in **both** engines:

1. In `src/bluekite/governance/guard.py`, add a fact: the status of the order owner's account
   (`"open"` or `"closed"`). Read it from the shop, not from the model.
2. In `src/bluekite/governance/policy.py`, add the rule to `RULES`.
3. In `policies/sam.cedar`, add the same rule as a `forbid`. Pass the new fact to Cedar in
   `src/bluekite/governance/cedar_policy.py` (an attribute of the `Order` is a good place).
4. Add a row to the table in `tests/test_policy.py`.

## Done when

```
uv run pytest exercises/check_s03.py -q
uv run pytest -q
```

Both pass. The check runs on both engines, so they must agree.

Solution: `git checkout s03-solution`.
