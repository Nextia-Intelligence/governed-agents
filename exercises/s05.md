# Exercise 5: a limit per tool

**Time:** about 20 minutes.

The loop detector stops the same call with the same arguments. But a confused agent can also
refund the same order again and again with a slightly different amount each time:
$5.00, then $5.01, then $5.02. Each call is "new", so the loop detector does not see it.

## Your task

In `src/bluekite/governance/budgets.py`:

1. Add a limit `refunds_per_run: int = 2` to `Limits`.
2. In `before_call()`, stop the run when Sam asks for a third `issue_refund` in the same run,
   whatever the arguments are. Use the reason `refunds · 3 of 2 per run`.
3. Show the new limit in `bluekite budget` (in `src/bluekite/cli.py`).
