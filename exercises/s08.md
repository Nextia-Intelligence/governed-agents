# Exercise 8: a new rule for the attack suite

**Time:** about 25 minutes.

The attack suite in `tests/attacks/` runs every ticket and variant, and then checks a list
of things that must never happen (`INVARIANTS` in `tests/attacks/invariants.py`). An
invariant does not care how a control works. It only looks at the result.

## Your task

1. In `tests/attacks/invariants.py`, write a new invariant
   `big_refunds_were_approved(db, run, lines)`. It returns a problem for every refund above
   $25.00 that has no approval from a person in the same run (status `approved`, or `used`
   once the approved call has run). Tip: the `refunds` table has the `run_id`; the
   `approvals` table has `run_id`, `tool` and `status`.
2. Add it to `INVARIANTS`.
3. Run `uv run pytest -q tests/attacks`. It still passes.
4. Now break a control on purpose: in `policies/sam.cedar`, change `2500` to `250000` in
   the rule `refund-over-25-needs-human`, and do the same in `policy.py`. Which tests fail?
   Change it back.

## Done when

```
uv run pytest exercises/check_s08.py -q
uv run pytest -q
```

Both pass.

Solution: `git checkout s08-solution`.
