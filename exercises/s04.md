# Exercise 4: an agent can never approve

**Time:** about 15 minutes.

An approval only means something if a person gives it. Today, anyone can type
`bluekite approve A-0001 --by sam`, and Sam's own request is approved "by Sam".

## Your task

In `src/bluekite/governance/approvals.py`, change `decide()` so that it raises
`ApprovalError` when:

1. `by` is empty, or
2. `by` is the agent that asked for the approval (the `agent` field of the approval).

Then try it: `bluekite run T-1002`, then `bluekite approve A-0001 --by sam`. You see a clear
error, and the approval is still pending.
